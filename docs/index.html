Technical Overview

Designed around predictable frame pacing, low background memory, and direct hardware access.

Direct USB HID (No Ring-0 Drivers)

Runs completely in Windows user-space via HidSharp with pre-allocated byte buffers on a dedicated 60 FPS loop. Safe for Vanguard and Ricochet.

Low-RAM Tray Suspend

Minimizing to the system tray suspends the WebView2 Chromium renderer via TrySuspendAsync() while keeping the C# hardware loop active.

Per-Channel HID Calibration

Fix swapped RGB / GRB / BRG / RBG channels per header and step through individual green LEDs to calibrate exact fan and strip counts.

Hot-Reload Lua Plugins

Drop .lua shader scripts into Plugins/ to load them live via MoonSharp without restarting the application.

DXGI Ambilight & WASAPI Audio FFT

Captures screen colors using GPU Desktop Duplication and analyzes 32-band loopback audio for reactive lighting.

Game Profiles & Local Web Remote

Bind lighting presets to .exe processes, control your setup over LAN via localhost:5050, or press Ctrl+Alt+L for instant blackout.
